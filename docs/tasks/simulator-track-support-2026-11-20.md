## Exact source selection and recovery

- Assetto Corsa uses the exact track directory and variant reported by the reader. Automatic discovery consults the explicit game root, Steam's registered root and per-title manifest install directories. It can continue across incomplete roots. Exact missing-source evidence takes precedence over unrelated library failures, such as an offline drive in Steam's library list. A sibling layout, nested AI backup or sole available variant cannot supply an absent identity.
- Source receipts bind AC fast and pit AI files, layout `data/map.ini`, layout UI and fallback UI. Missing dependencies are recorded and can invalidate a receipt when they appear. AC and SCE include canonical and requested paths, content hashes, extractor generation, exact export identity and payload digest. Unrelated Companion releases leave current geometry receipts valid. The receipt schema change requires one rebuild of the old cache.
- The EVO cache retains package source and build checks, verified ideal/pit hashes, the surface manifest and payload verification. Its cache lives outside the upload outbox. A changed package build or source manifest requires source revalidation.
- SCE accepts an exact, unique AIW stem or nearby GDB `TrackName`. The installed `InterlagosGP.AIW` has the GDB title `Interlagos`, matching the recorded test reader's scoring name convention. An exact title completion is delivered to that request while the export retains the AIW stem. The installed census found collisions for `Brasilia`, `curitiba`, `Interlagos Cafe` and `Interlagos Historic`. Ambiguous identities and reused export stems are refused.
- Missing sources and temporary reads/writes can be requested again without a track switch. The reader uses bounded delays and accepts only the current request's completion. Fatal geometry validation is surfaced separately. Background preparation and validation keep game disk I/O off the telemetry thread.
- The track outbox ledger is keyed by server, while track ingestion scopes files by the paired account. Account switching requires a safe ownership/reconciliation contract before resetting the ledger or resending old payloads. This source repair has no account-side effects.

## Union Island and pit validation

The installed `union_island/freeroam` layout has an empty `ai` directory and its own `map.png` and `data/map.ini`. The calibrated raster could support a separately validated top-down view. Perspective geometry would require a selective KN5 scene/road import with surface semantics and branching topology. The traffic layout has a different route and cannot supply freeroam geometry.

In `union_island/traffic`, the 11,809,296-byte fast and pit spline files have identical SHA-256 `adbe86d2a26b2eba978b5618d1c1f754926e5bbfc6cc64ec00c83ce26e288227`. The file contains 21,611 points, with 33,206.02 m of stored progress. Treating that copy as an independent pit lane would draw the entire main route again. The parser omits byte-identical and coordinate-identical paths and omits near-full closed loops on closed layouts. The spatial proximity check covers each pit point and caps point comparisons at two million. SCE uses the same proximity bound and caps AIW branch traversal at four visits per waypoint on average across all candidate starts. A rejected pit path leaves the validated main layout usable.

## High Force and AI lookup grids

The installed AC corpus counted 551 `fast_lane.ai` files, including 10 backups, with 518 accepted and 33 refused before the prefix reader change. Five refusals came from the previous 64 MiB physical-source limit. Those High Force variants' fast and pit files each have v7 headers with 66,468 points and a file size of 105,211,608 bytes. Their geometry uses a 6,115,076-byte prefix. The remaining 99,096,532 bytes fall in the game's lookup-grid area, which the geometry parser skips.

All five High Force fast splines have zero stored distance at every point. An independent bounded read confirmed their 66,468 finite, correctly indexed position samples and matching detail counts. The spatial chords total 102.32 km while layout metadata says 50 km. The prefix reader exposes the actual validation failure, `ai_dist_zero`, and High Force remains unavailable as automatic native geometry.

The parser now reads at most 18,400,020 bytes of geometry per AC spline, based on its validated point count. The receipt worker streams the full SHA-256 for each AC fast or pit spline, including the skipped suffix, up to 128 MiB per file and 256 MiB of splines per capture phase. A cold build captures the source before and after extraction. A warm lookup captures it once. These phases run on the worker when it receives a layout request. The 64 MiB XTRK unpacked limit and other source dependency limits still apply.

The three archived AC recordings establish X/Z alignment for their local samples. They do not establish asphalt widths or live acceptance for other mods. Remaining interactive checks are a cold-cache stock circuit, an installed mod with AI and an AI-less or open layout, with left/right and first-entry readiness observed in the built Companion.
